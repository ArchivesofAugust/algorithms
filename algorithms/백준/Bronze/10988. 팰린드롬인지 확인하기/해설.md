# 10988. 팰린드롬인지 확인하기 — 해설

## 핵심 아이디어

문자열이 팰린드롬인지 확인하는 가장 기본적인 방법은 **투 포인터**: 왼쪽 끝(left)과 오른쪽 끝(right)에서 시작해 안쪽으로 좁혀가며 두 글자를 비교한다.

## 접근 방법

- `left = 0`, `right = length - 1`로 시작
- `s[left] != s[right]`이면 즉시 팰린드롬 아님으로 확정하고 종료 (조기 종료 가능)
- 같으면 `left++`, `right--`로 안쪽으로 이동
- `left >= right`가 되면 전체가 팰린드롬

문자열을 뒤집어서(`reverse`) 통째로 비교하는 방법도 있지만, 이는 뒤집은 문자열을 새로 만드는 비용(O(N) 공간)이 든다. 투 포인터는 추가 공간 없이 O(1) 공간으로 같은 일을 한다.

## 시간/공간 복잡도

- 시간: O(N) — 최악의 경우(실제 팰린드롬일 때) N/2번 비교
- 공간: O(1) — 인덱스 두 개만 사용

## 헷갈렸던 점 / 주의할 점

- 조기 종료(break)를 넣으면 팰린드롬이 아닌 경우 평균적으로 더 빨리 끝난다 (문제 크기가 작아 성능에 큰 영향은 없지만 좋은 습관).
- 이 문제는 이후 1213(재배열), 10942(구간 쿼리), 1509(분할)로 이어지는 팰린드롬 시리즈의 가장 기초 형태 — 투 포인터가 "팰린드롬 판별"의 기본 연산이라는 점을 여기서 확립해두면 뒤 문제들(특히 10942의 DP 점화식)에서 재사용된다.
